# Personal Portfolio Website

A responsive personal portfolio starter built with plain HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in a browser. For a local dev server, run:
`python3 -m http.server 8000`
Then visit `http://localhost:8000`.

## Before publishing
1. Replace `[YOUR NAME]`, `Your Name`, and `YOUR NAME` with your name.
2. Replace `hello@example.com` with your email in `index.html` and `script.js`.
3. Update social profile links.
4. Replace sample project concepts and education placeholders with your real information.
5. Add real project thumbnails, live preview URLs, and GitHub repository URLs.
6. Update the page title and meta description.

The contact form uses `mailto:` and does not submit to a server. Connect a backend or form service if you need direct form submissions.
